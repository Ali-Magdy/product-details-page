# Product Showcase Page

Build the Product Details page based on the attached reference image.

The page should closely reproduce the provided design, including:

- Header / Navbar

- Product image gallery

- Product name

- Product price

- Available product options such as size/volume

- Product availability

- Add to Cart button

- Product information / description

- Scent notes or ingredients section

- Related products section

- Footer

Follow the reference image as closely as possible in:

- Layout

- Spacing

- Typography

- Colors

- Borders

- Button styles

- Image sizes

- Card styles

- Alignment

Do not redesign the page or add unnecessary sections.

Make the page responsive for desktop, tablet, and mobile.

Use clean, reusable React components and keep the Product Details functionality isolated inside the products feature.

Do not invent business requirements that are not visible in the reference or explicitly mentioned above.
